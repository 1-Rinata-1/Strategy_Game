## Пошаговая игра-стратегия на двоих
Разработанная игра представляет собой пошаговую стратегическую дуэль с элементами управления ресурсами и принятия решений. 
Цель игры – захватить главное здание противника, параллельно обеспечивая защиту и экономическое развитие своей цивилизации.
В игре присутствуют следующие цивилизации, имеющие собственные пассивные бонусы:
- Эльфы: имеют увеличенную территорию на начальном этапе игры;
- Гномы: в начале игры обладают повышенным количеством золота;
- Орки: имеют повышенный уровень стойкости у главного здания.

В каждой из цивилизаций присутствуют следующие типы индивидуумов, способных выполнять определенные задачи:
- Строитель: может построить или усилить здание (дом или башню);
- Воин: способен занять нейтральную клетку для расширения территории или атаковать клетки на территории врага;
- Целитель: восстанавливает стойкость у главного здания своей цивилизации.

Типы зданий, используемых в игре:
- Главное здание: игрок, разрушивший главное здание противника, становится победителем;
- Дом: приносит своему владельцу по 5 единиц золота каждый ход;
- Башня: защищает клетку, на которой стоит, от захвата противником; на разрушение башни противник должен потратить 30 монет.

Игра начинается с выбора цивилизации для каждого игрока. Основной игровой цикл построен вокруг поочередных ходов противников. 
Во время своего хода активный игрок должен выбрать роль и выполнить одну из доступных выбранному индивидууму задач. 
Игра заканчивается, когда одному из игроков удается разрушить главное здание противника.

## При реализации игры использовались следующие паттерны проектирования:
- Паттерн Фабричный метод
- Паттерн Абстрактная фабрика
- Паттерн Строитель
- Паттерн Прототип
- Паттерн Одиночка
